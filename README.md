# CULTURE DRIVE — 숙명여대 공강·하교 문화예술 혜택 드라이브

> 숙명여자대학교를 출발점으로 공강·하교 시간에 방문하기 좋은 문화예술 공간과 서울의 기간 한정 행사를 찾아보고, 나이와 일정에 맞는 할인 혜택을 확인하는 웹 서비스입니다.

## 배포 주소

- **서비스 URL:** 배포 후 Vercel 주소 입력 예정
- **배포 플랫폼:** [Vercel](https://261117vibecoding.vercel.app/)
- **배포 설정:** 저장소에 포함된 `vercel.json`에서 Vite 빌드 명령과 `dist` 출력 디렉터리를 설정합니다.


## 사용 방법

### 1. 시작 및 프로필 설정

1. 웹 서비스에 접속합니다.
2. 우측 상단의 **로그인**을 누릅니다.
3. 닉네임과 만 나이를 입력합니다. 이메일은 선택 항목입니다.
4. **로그인 저장**을 누르면 입력한 만 나이를 할인 대상 판정에 반영합니다.

※ 이 기능은 실제 계정 인증이 아닌 데모용 프로필 입력 기능입니다. 프로필은 현재 브라우저의 `localStorage`에 저장되며, 서버 계정이나 다른 기기와 동기화되지 않습니다.

### 2. 조건 설정 및 검색

검색 전 필터 영역에서 원하는 조건을 선택한 뒤 **검색**을 누릅니다.

- **종류:** 전체, 상설 혜택 장소, 기간 한정 행사
- **내 시간표:** 제한 없음, 공강 1시간, 1시간 30분, 2시간
- **나이 기준(상설):** 만 24세 이하, 만 25~29세 기준 — 중복 선택 가능
- **분야:** 박물관, 미술관, 문화예술, 기타 / 전시, 공연, 영화, 체험·축제
- **할인율:** 전체, 무료, 50% 이상, 30% 이상
- **행사 조건:** 청소년·청년 할인만, 현재 진행 중만, 7일 안에 종료되는 행사, 마감 임박순 정렬
- **검색어:** 행사명, 장소, 자치구로 검색

### 3. 결과 확인 및 북마크

- 상설 문화혜택은 거리순 또는 할인율순으로 정렬할 수 있습니다.
- 기간 한정 행사는 행사 기간, 운영시간, 장소, 요금 및 할인 정보를 확인할 수 있습니다.
- 카드의 별표 버튼으로 장소와 행사를 북마크할 수 있습니다.
- **북마크만** 필터를 켜면 저장한 항목 중 현재 필터 조건에 맞는 항목만 표시합니다.
- 카드의 상세 링크를 누르면 해당 기관 또는 행사 상세 페이지로 이동합니다.

### 4. 드라이브 장면

화면 상단의 픽셀 자동차 장면은 선택한 장소 또는 행사를 목적지로 표시합니다. **주행 정지 / 드라이브 재생** 버튼으로 장면 애니메이션을 멈추거나 다시 재생할 수 있습니다.

## 화면

현재 앱은 검색 전 필터 화면과 검색 후 결과 화면을 중심으로 구성되어 있습니다.

| 화면 | 주요 구성 |
|---|---|
| 메인 화면 | 상단 내비게이션, 프로필 버튼, 픽셀 자동차 주행 장면, 서비스 소개 |
| 검색 전 화면 | 종류, 공강 시간, 나이, 분야, 할인율 및 행사 조건 필터 |
| 검색 결과 화면 | 상설 문화혜택 카드, 기간 한정 행사 카드, 거리·할인·마감 정보, 북마크 |
| 프로필 패널 | 닉네임, 이메일(선택), 만 나이 입력 및 로그아웃 |

### 화면 캡처

아직 저장소에 실제 화면 캡처 파일이 포함되어 있지 않습니다. 배포 또는 로컬 실행 후 아래 위치에 캡처 이미지를 추가하면 README에서 바로 확인할 수 있습니다.


캡처를 추가한 뒤 아래 예시처럼 이미지 경로를 연결해 주세요.

## 만든 과정

1. **서비스 목적 정의**  
   숙명여대 학생이 공강이나 하교 시간에 갈 수 있는 주변 문화예술 공간과 청년 할인 정보를 빠르게 찾는 것을 목표로 정했습니다.
2. **데이터 구성**  
   상설 문화혜택 목록은 별도 데이터 파일로 관리하고, 서울문화포털 문화행사 CSV를 가공한 150건의 행사 데이터를 `src/data/events.json`에 정리해 기간 한정 행사 검색에 사용합니다.
3. **화면 및 컴포넌트 구성**  
   React 컴포넌트를 메인 앱, 필터 패널, 행사 목록, 북마크 버튼, 픽셀 드라이브 장면 등으로 나누어 구현했습니다.
4. **검색·필터 기능 구현**  
   공강 시간, 분야, 할인율, 행사 유형, 검색어, 북마크 조건을 조합할 수 있도록 필터 로직을 구성했습니다.
5. **프로필 기반 개인화**  
   입력한 만 나이에 따라 적용 가능한 상설 할인 기준과 행사 대상 연령을 판정하도록 했습니다. 만 24세 이하와 만 25~29세 기준은 독립적으로 선택할 수 있습니다.
6. **기간 및 운영시간 판정 보완**  
   날짜만 비교하지 않고 한국 시간(Asia/Seoul) 기준 현재 날짜·요일·분을 확인합니다. 종료일의 운영 종료 시각이 지났거나 해당 요일이 휴관이면 행사 목록에서 제외합니다. 화면이 열린 상태에서도 30초마다 유효 기간을 다시 계산합니다.
7. **검증 및 배포 준비**  
   연령·행사 기간 판정 테스트를 추가하고, TypeScript와 Vite 빌드 및 Vercel 배포 설정을 프로젝트에 포함했습니다.

## 데이터 및 유의사항

- 기간 한정 행사 데이터는 서울문화포털 문화행사 데이터를 가공한 정적 JSON 파일(현재 150건)을 사용합니다. 실시간 API 연동이 아니므로 최신 정보와 잔여 좌석을 보장하지 않습니다.
- 상설 할인 데이터는 프로젝트에 등록된 목록을 기반으로 표시합니다. 실제 할인 조건, 증빙 서류, 운영 여부는 방문 전 기관의 공식 안내를 확인해야 합니다.
- 거리와 왕복 소요시간은 프로젝트 데이터에 입력된 추정값이며, 실시간 교통·경로 탐색 결과가 아닙니다.
- 운영시간 문자열에 종료 시각이 명확히 기록되지 않은 행사는 날짜만으로 정확한 당일 종료 시점을 판정할 수 없습니다. 이 경우 종료일의 마지막까지 유효한 것으로 처리됩니다.
- 프로필과 북마크는 브라우저 로컬 저장소에 저장됩니다. 브라우저 데이터 삭제 또는 다른 기기 사용 시 기존 정보가 유지되지 않을 수 있습니다.

## 프로젝트 구조

```text
src/
├── app/          # 메인 앱 및 전역 스타일
├── components/   # 필터, 행사 목록, 북마크 UI
├── data/         # 상설 혜택 및 행사 데이터
├── lib/          # 저장소 및 문화행사 판정 로직
├── scene/        # 픽셀 드라이브 장면
├── styles/       # 디자인 토큰
└── types/        # TypeScript 타입 정의
public/
└── assets/       # 이미지 에셋
```
